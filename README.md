# YT Manager — 공개 페이지

YT Manager 의 Google OAuth 동의 화면에 등록한 홈페이지·개인정보처리방침·서비스 약관입니다.
GitHub Pages 로 서비스되는 정적 페이지 3개뿐이고, 코드나 비밀값은 없습니다.

## 주소

| 페이지 | 주소 | 파일 |
|---|---|---|
| 홈 | https://boosari.github.io/ytmanager-pages/ | `index.html` |
| 개인정보처리방침 | https://boosari.github.io/ytmanager-pages/privacy.html | `privacy.html` |
| 서비스 약관 | https://boosari.github.io/ytmanager-pages/terms.html | `terms.html` |

이 주소들은 Google Cloud 콘솔 → Google 인증 플랫폼 → 브랜딩에 등록되어 있습니다. 승인된 도메인은 `boosari.github.io` 입니다.

## 주의

- **이 저장소는 public 으로 두어야 합니다.** 무료 플랜에서 private 으로 바꾸면 GitHub Pages 가 꺼져 위 주소가 모두 404 가 되고, 동의 화면 링크가 깨집니다.
- 파일 이름이나 저장소 이름을 바꾸면 주소가 바뀌므로 Google 브랜딩 설정도 같이 고쳐야 합니다.
- 페이지의 "문의" 링크는 이 저장소의 GitHub 이슈로 연결됩니다.
- 검색엔진에 노출되지 않도록 모든 페이지에 `noindex` 가 들어 있습니다.

## 수정하는 법

HTML 을 고쳐 `main` 에 푸시하면 1~2분 뒤 위 주소에 반영됩니다. 개인정보처리방침이나 약관 내용을 바꾸면 페이지 안의 시행일도 함께 고칩니다.
