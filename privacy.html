개인정보처리방침

YT Manager · 시행일 2026년 10월 1일

홈서비스 약관

YT Manager(이하 "서비스")는 운영자가 직접 소유·관리하는 유튜브 채널의 지표를 보기 위한 비공개 셀프호스팅 도구입니다. 이 방침은 서비스가 Google 계정과 YouTube에서 받는 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 정보

  • 로그인 정보: Google 계정의 이메일 주소, 이름, 프로필 사진. 로그인이 허용된 계정인지 확인하는 데 씁니다.
  • OAuth 토큰: 채널을 연결할 때 Google이 발급하는 리프레시 토큰. 암호화(AES-256-GCM)해 저장하고 YouTube 데이터를 읽는 데만 씁니다.
  • YouTube 데이터: 연결한 채널과 영상의 정보, 분석 지표(조회수, 시청시간, 구독자 증감, 시청 지속률, 트래픽 소스, 시청자 구성 등), 영상에 달린 공개 댓글, 권한을 허용한 경우 수익 지표.

2. 이용 목적

수집한 정보는 채널 운영자가 자기 채널의 성과를 확인하고 분석하는 데에만 씁니다. 광고, 프로파일링, 판매, 인공지능 모델 학습에 쓰지 않습니다.

3. 저장과 보관

정보는 운영자가 관리하는 서버의 데이터베이스에만 저장됩니다. 채널을 연결해 두는 동안 보관하며, 운영자는 서버 장애에 대비해 같은 서버에 백업본을 둡니다.

4. 제3자 제공

정보를 제3자에게 판매하거나 제공하지 않습니다. 단, 운영자가 선택 기능인 "댓글 요약"을 켠 경우에는 요약을 만들기 위해 공개 댓글 텍스트가 Anthropic의 Claude API로 전송될 수 있습니다. 이 기능은 운영자 화면에 요약을 보여 주는 데만 쓰입니다.

5. Google API 서비스 사용자 데이터 정책

서비스가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. YouTube API 서비스

서비스는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침도 함께 적용됩니다.

7. 권한 철회와 삭제

  • 언제든 Google 계정 → 타사 액세스에서 YT Manager의 접근 권한을 철회할 수 있습니다. 철회하면 서비스는 더 이상 데이터를 읽을 수 없습니다.
  • 운영자에게 요청하면 해당 채널에 대해 저장된 토큰과 데이터를 삭제합니다.

8. 변경
